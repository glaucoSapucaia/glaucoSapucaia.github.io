Sistemas

NexusCore é um sistema web focado na gestão interna de informações, com controle rigoroso de acessos e ações por nível hierárquico. Ideal para organizar, proteger e administrar dados de forma centralizada, segura e eficiente.

DataWeaver automatiza a extração de dados de PDFs hospedados na web. O sistema busca documentos, extrai tabelas, trata os dados, gera CSVs e os armazena em um banco de dados. Com API e frontend intuitivo, facilita consultas e visualização, tornando o processamento de dados mais rápido e eficiente.

SortLab executa algoritmos de ordenação, mede performance, exibe gráficos com Matplotlib (via PyQt5) e Plotly, e gera um relatório final em PDF contendo os dados e visualizações com o ReportLab.

AutoTri é um bot que automatiza a triagem de processos/protocolos. A ferramenta acessa sistemas, realiza buscas, extrai informações, obtém anexos/documentos, organiza dados e gera um relatório centralizado com anexos e links.
